Rhino Mode

Unofficial Rhino-style workflow for Blender, switchable on and off. This page is the project's own extension repository: add it to Blender once, then install and update Rhino Mode from inside Blender.

Add it in Blender

  1. Edit > Preferences > Get Extensions: open Repositories at the top right, press +, choose Add Remote Repository.
  2. Paste this URL, tick Check for Updates on Startup, press Create:
https://ren18161849172-byte.github.io/rhino-mode/index.json
  1. Search for Rhino Mode in Get Extensions and press Install.

Blender has to be allowed online: Preferences > System > Network > Allow Online Access. Blender 4.2 LTS or newer.

在 Blender 里添加

  1. 编辑 > 偏好设置 > 获取扩展：点右上角的 存储库，按 +，选 添加远程存储库。
  2. 粘贴上面的地址，勾选 启动时检查更新，点 创建。
  3. 在“获取扩展”里搜 Rhino Mode，点 安装。以后有新版本也在这里更新。

需要先允许 Blender 联网：偏好设置 > 系统 > 网络 > 允许联机访问。需要 Blender 4.2 LTS 或更新的版本。
